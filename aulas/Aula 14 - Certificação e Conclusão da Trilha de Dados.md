## 1. Parabéns! Você completou a Trilha de Dados

Ao concluir o Caso 005 (Normalização e Relacionamentos) e o Caso 006 (TechBrasil: OLTP/ETL/DW/OLAP), você percorreu o caminho completo de um analista de dados no mundo real:

```
Estagiário de TI
    ↓ (Caso 005: Normalização)
Analista de Dados Jr

Pronto para o mercado
```

| Tópico | Onde foi praticado | Aplicação real |

## 3. Seu certificado

Ao concluir a trilha, o jogo gera um **certificado digital** com:

- Seu nome (definido no início do jogo).
- Cargo alcançado: **Analista de BI / Dados Pleno**.
- Data de conclusão.
- Pontuação total e estrelas por missão.
- Badges conquistados:
  - 🏆 **"Caçador de Anomalias"** — completou o Detective de Anomalias (Caso 005)
  - 📊 **"Salvador do Trimestre"** — entregou o dashboard do CFO (Caso 006)
  - ⚡ **"Otimizador"** — reduziu o custo de query com índices (Caso 006)

O certificado pode ser exportado em PDF e compartilhado.

## 4. Tela "Meu Portfolio"

O jogo tem uma tela de portfolio que mostra:

- Todos os casos concluídos.
- Certificados e badges.
- Progresso geral na trilha.
- Estatísticas (total de queries escritas, estrelas, tempo jogado).

## 6. Recursos recomendados

- **SQL avançado:** recursive CTE, window functions avançadas, JSON no SQLite.
- **Cloud DW:** BigQuery (GCP), Redshift (AWS), Snowflake.
- **Orquestração ETL:** Apache Airflow, dbt.
- **Visualização:** Power BI, Metabase, Grafana.
